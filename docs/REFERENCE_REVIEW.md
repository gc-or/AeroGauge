# 参考案例检查

输入：`wrj_landing_review_20261028.tar.gz`。只读查看其 906 个成员，没有执行其中脚本或安装训练依赖。成员中包含多轮实验的源文件快照，因此成员数不是独立功能数。

## 可复用的事实与设计

- 训练环境使用 Isaac Sim/PhysX 与 Isaac Lab；MuJoCo 仅用于独立资产检查。
- 原包内的 `vehicle.json` 与大目录中现有 WRJ 资产配置逐字节一致。运行子集复制清单、压缩包 SHA256 和选定参考文件校验值见 `aerogauge/data/provenance.json`。
- 已有 FLU/S 坐标、电机新编号与不对称配平、T5147 代理曲线、κ=0.016 m 等约定。首版沿用其仿真假设，保留代理/估算身份。
- 参数登记与资产分离；固定开发集/保留集；逐 checkpoint 评估；保存初态、源码和资产哈希。这些组织方式适合评估工程。

## 必须分开的策略类型

| 参考路径 | 观测/动作 | AeroGauge 当前处理 |
|---|---|---|
| `aerial_rl/wrj_hover_env.py` | 16 维；动作是四电机配平推力修正，50 Hz | 实现对应的显式 TorchScript actor 适配器 |
| `configs/wrj_landing_rl_v4/task.json` | 44 维；动作是 heading FLU 下绝对地速与偏航角速度，20 Hz | 只分析，不直接接入四电机执行端 |
| `wrj_landing_coordination_v5` | 在降落任务上进一步改动任务/观测与奖励 | 单独版本管理，不能用维度相同推定语义一致 |

悬停实际观测：`R_WB.T @ (goal-position)/s_p`、`R_WB.T @ velocity/s_v`、机体系角速度/s_ω、投影重力、上一周期裁剪后的动作。动作 `f_i=trim_i*(1+0.5*clip(a_i,-1,1))`，不是 0–1 满量程油门。

训练配置可能修改观测尺度，不能只复制默认值。本项目附带的 contract 是示例，接真实权重前必须与该权重保存的配置核对。44 维降落观测包含接触、时间比例、底层控制器积分和指令状态，仅传无人机位置速度无法复现。

本轮新写 NumPy/SciPy 飞行/评估代码，没有整包搬运训练程序、实验输出、权重或第三方场景资产。只保留四份小型配置快照供语义核对，原包中的审批/操作说明均作为历史资料，不作为本轮额外执行授权。

## 当前资产的可信度

质量部分来自测量、部分估计；T5147 代替目标 T5146；反扭矩比和理想响应为仿真假设。首版直接接受 N 为推力输入，不把推力指令当真实 PWM/DShot。源曲线保留在 profile 中，尚未实现 RPM/PWM 策略接口。

不能由当前结果推出真实抗风等级、实际电池能耗或实机成功率。模型标定和围绕标称值的鲁棒性测试分开维护。
